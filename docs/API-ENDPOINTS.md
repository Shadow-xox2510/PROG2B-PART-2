\# RaceDay API Endpoint Reference



\## Overview



The RaceDay API provides endpoints for user authentication, profiles, events, enrolments and results.



\## Main Controller Areas



\- \*\*Authentication:\*\* Registration and login.

\- \*\*Profiles:\*\* Access to user profile information.

\- \*\*Events:\*\* Event-related operations and permissions.

\- \*\*Enrolments:\*\* Participant enrolment operations.

\- \*\*Results:\*\* Event results and participant result access.



\## How to Verify Endpoints



1\. Open the project in Visual Studio.

2\. Run the RaceDayAPI project.

3\. Open the Swagger page if Swagger is enabled.

4\. Review the available HTTP methods, routes and required request data.



\*\*Note:\*\* Refer to the controller source files for the exact routes and request formats implemented in this project.
